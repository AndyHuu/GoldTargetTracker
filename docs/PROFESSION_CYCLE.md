# 专业循环（2.3.0-rc1）

进入金币进度条设置，选择左侧“专业循环”。面向同一角色的工程学回收、制造和附魔分解。已有“安迪循环”宏仍可使用；也可点“创建循环宏”，再从 `/m` 拖到动作条。每次触发宏时决定下一步，事件只维护等待状态。

## 三个独立列表

- **回收材料**：拖背包物品到输入框后点“添加”，也可输入物品名称、物品链接或编号。只接受工程学“循环回收”配方支持的材料，按单个堆叠每五个一组批量回收。高低星编号不同，需要分别添加。
- **制造配方**：在工程学窗口选中已学会的普通物品配方，点“添加当前配方”；也可输入配方编号。按可制造次数与普通背包空位限制批量制造。材料不足会尝试下一项。不处理再造、附魔、回收和采集配方。
- **分解物品**：同回收材料的添加方式。只会选择列表中的背包物品，每次触发拆一件。请确认加入的物品可以分解；同一编号的所有背包物品都属于候选，先移走需要保留的物品。

每一行均可“移除”，每个列表最多 20 项，按添加顺序选择。清空某个列表会跳过该步骤，重载不会补回默认条目。制造成品不会自动加入分解名单。配方编号与物品编号是不同的编号。

首次默认回收两种光明亚麻布卷（239700、239701），制造永恒之核腕扣配方（1229866），分解永恒之核腕扣（245341）。设置按角色保存，与账号金币历史分离。

## 执行顺序与等待

1. 有分解名单物品时，分解一件。
2. 否则有足够回收名单材料时，批量回收当前堆叠。
3. 否则选择第一个可制造的配方，按背包容量批量制造。

回收与制造至少要求三个普通背包空格，并预留两个空格。多重制作等额外产出仍可能占满背包。读条、拾取、鼠标持有物品、战斗和正在执行的批次期间不启动下一步；战斗或当前制作期间不允许修改列表。列表停用后保留内容。

批次停止事件为主要完成依据，另有三秒无读条活动的恢复等待；真实延迟、连续点击和游戏受保护调用仍需客户端验证。回收配方未加载、不可回收条目或不能分解的条目可能使当前步骤停住，检查界面提示并移除不合适条目。

## 更新兼容

整合版保持 `AndyCraftCycleButton` 宏目标。若旧 AndyCraftCycle 仍启用，整合版在其加载后接管旧按钮，旧按钮事件不再运行。建议停用旧独立插件。自动创建宏不会覆盖同名但内容不同的宏，也不会删除其他宏。

金币变量 `GoldTargetTrackerData`、`GoldTargetTrackerBackup` 保持原逻辑，循环单独使用 `GoldTargetTrackerCycleData`（SavedVariablesPerCharacter）。发现循环数据结构不兼容时保留原数据并暂停循环，金币功能继续工作。

## 验证

123 项 Lua 5.1 模拟回归通过，包含原金币功能 98 项与循环 25 项：默认/空列表、增删与过滤、列表优先级、背包空间、批次等待、战斗阻止、宏冲突、旧按钮接管和设置页宽度适配。模拟检查不是客户端验收。

客户端待验证：重载后金币历史保持、三个列表增删与再次重载保存、当前配方添加、旧宏继续工作、逐步实际回收/制造/分解、拾取与连续批次期间等待，以及窄窗口视觉布局。
